# NOVA Shop

A polished, responsive e-commerce storefront demo built with plain HTML, CSS and JavaScript.

## Live Demo

https://jimmmzzzzz.github.io/Shop/

> **Demo only:** This project is a front-end e-commerce showcase and is not a live production store. Checkout and payments are not connected to a real payment processor or backend.

## Features

- Responsive desktop and mobile layout
- Product photography
- Category filters and live search
- Product quick-view modal
- Working cart drawer
- Quantity controls and cart totals
- Cart persistence with localStorage
- Promo/announcement bar
- Newsletter form
- Accessible navigation and controls

## Run locally

Open `index.html` in a browser, or use any simple local server.

## Deploy

This project is static and can be deployed directly with GitHub Pages, Cloudflare Pages, Netlify or Vercel.

## Notes

Checkout is intentionally a demo action. Connect a payment provider and backend before accepting real orders.

Product photography is loaded from Unsplash.
